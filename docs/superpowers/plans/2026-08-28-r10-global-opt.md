# R10 · 全空间总攻——Optuna 全局优化验证 B3 全局最优性（2026-08-28）

## 1. 战役定位

用户裁决：不记成本、最深入最全面、用现成轮子探索所有可能方向。R8（参数双
口径穷尽）+R9（七过滤面全负）后的科学先验是"B3 即全局最优"，但**该假设从未
被真正检验**：R2-R9 全部搜索范式是「从 B3 出发的逐维贪心/局部网格」——坐标
下降天然困在出发盆地，全空间联合搜索（多起点+全局采样器）从未做过。本轮
补上这块穷尽性证明；若真找到第二盆地即大发现。

### 1.1 轮子选择（调研结论）

- **Optuna 4.9.0**（已在 venv，ADR4 批准先例 `discovery/search.py`）：
  混合离散空间（suggest_categorical）+ 昂贵黑盒 + 断点续跑（sqlite storage）
  + multivariate TPE——[系统对比研究](https://arxiv.org/pdf/2201.06433)与
  [2025 社区共识](https://www.reddit.com/r/MachineLearning/comments/pev04l/)均
  列其为首选项。
- SMAC3/nevergrad 为备选（Stage 2 交叉验证采样器，见 §3）。
- 不引入 vectorbt/backtrader 等量化黑盒（ADR4 红线不变）。

### 1.2 与既有搜索的本质差异

| 维度 | R2-R9（贪心/局部网格） | R10（全局） |
|---|---|---|
| 范式 | 坐标下降，单步单维 | 33 维联合采样 |
| 起点 | B3 及其邻域 | B3 warm start + 50 随机启动点 |
| 采样器 | 手工档序 | TPE multivariate 后验集中 |
| 停机 | 时间预算 | 收敛驱动（300 trial 无改进） |
| 断点 | state.json | optuna sqlite study 原生 |

## 2. 预登记协议（发射前写死）

### 2.1 搜索空间（33 维 categorical，档位=发射前定死）

- **24 参数键**：B3 base 值 ∪ R8 PHASE_A/B_GRID 档（程序化并集，B3 值必在
  choices 内）。
- **2 个 R8 未扫键**：momentum_gate [None,-0.05,0.0,0.05]、time_stop_days
  [None,5,10]（EXEC/ID_KEYS 清单内但从未进网格）。
- **R9 七过滤维**：D1 流动性 [3e4,1e5,2e5,5e5]、D2 周内 [None,no_mon,no_fri,
  mid_only]、D3 动量 [None,10/40 日窗±阈值 4 档]、D4 价格带 [None,3 档]、
  D5 量比上限 [None,3,5]、D6 深度带 [None,2 档]、D7 次新 [None,400]。
  （R9 单维全负结论不受染：联合空间允许维度交互，TPE 自学负梯度。）

### 2.2 目标与评估

- objective = inner 2021-24 deployable ann 的 **K=5 种子（0-4）中位**
  （CRN 与 R8/R9 同口径，可比）。评估管线复用 R9 Runner（import）。
- warm start：enqueue B3 全套（liquidity=1e5+零过滤）。

### 2.3 停机（收敛驱动，用户"不记成本"裁决=无时钟死线）

- 主停机：连续 **N_STALL=300 trial** best_inner 无 ≥+0.005 改进；
- 硬上限：MAX_TRIALS=3000（防真失控；≈3min/trial → 上限 ~6 天量级，
  收敛大概率先到）；
- 断点：optuna sqlite（study.db）+ state.json 双轨，崩了续跑。

### 2.4 终审（fail-closed 不变）

champion（study best trial 的 params+state）vs incumbent0（B3+1e5+零过滤）：
- K=21 种子配对 inner/outer；**采纳须 outer 中位 Δ≥0 且 ≥15/21 同向**；
- G3 逐年/G4 换手/G5 oracle 护栏全表展示（口径同 R9）；
- DRAFT 物化留手动（不写 experiments.db）。

### 2.5 Stage 2（条件分支，发射前登记）

- 若 champion≠B3：异种子 TPESampler（seed=7，startup=100 更探索性）独立
  study 复核（新 basin 需双采样器收敛到同域才算数；CMA-ES 不支持纯
  categorical 空间故不选用），再进终审；
- 若 champion=B3（同参数同状态）：RandomSampler 大样本对照（500 trial 均匀
  撒点验证无漏网高产区）后直接收档——B3 全局最优性即穷尽性证明。

### 2.6 红线

C2 内核零触碰；ADR-16 池子侧不进参数；pos_cap/max_positions/capital 不动；
闸中途不改；外层 holdout 只碰一次。

## 3. 已知局限

- TPE 在 33 维离散大空间有维数诅咒——multivariate+300 stall 长尾是接受
  的对价（不记成本裁决）；随机 Stage 2 是兜底对照。
- 识别缓存仅对重复 id_cfg 生效，TPE 新组合几乎全 miss（~2-3min/trial 是
  实测预期）；boot 重建 ~15min（断点续跑时唯一重复成本）。
- R9 幸存者偏差口径一致性继承（D1 档间差值有效）。
