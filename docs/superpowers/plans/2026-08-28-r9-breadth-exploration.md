## 2. 预登记协议（发射前写死）

### 2.1 口径

- 目标：inner 2021-24 段冻结 PM（4×7.5% 整手+min5+freeze@100w）×
  queue_order=random × 种子列表的**配对差值中位**（CRN）。
- outer 2025-26 = holdout，只进终审不进搜索。
- incumbent = B3 24 键（logs/r6_10_loop/state.json base），liquidity=1e5，
  零过滤——R8 终审 VETO 后维持的 incumbent 状态。

### 2.2 闸（两段式，与 R8 同款 + 过滤类换手放宽）

- Phase A 弱化晋升（K=3 种子 [0,1,2]）：Δ中位 ≥ +0.015 且 3/3 同向。
- Phase B 采纳（K=5 种子 [0-4]）：
  - G1 主闸：inner deployable Δ中位 ≥ +0.02；
  - G2 符号一致：≥4/5 种子同向；
  - G3 逐年不塌：inner 各年（21-24）deployable 中位恶化 ≤10pp；
  - G4 换手守卫：n_taken 中位 ≥ 基线 70%（D1 类）/ **≥50%（D2-D7 过滤类，
    预登记放宽——过滤天然砍信号，70% 对禁周一类探针结构性过紧）**；
  - G5 oracle 护栏：oracle 全期(2021-26) ann Δ ≥ −0.05。
- Phase C 终审（K=21 种子 0-20，配对 vs incumbent0）：outer holdout 中位
  Δ ≥ 0 且 ≥15/21 同向，否则整体否决（fail-closed 维持 incumbent）。

### 2.3 排程（硬预算 --hours 8）

Boot（freeze + 全湖首日表 + incumbent 锚，~30min）→ Phase A 广度扫描
（19 探针：D2-D7 后过滤近乎免费，D1 四档吃识别缓存增量，≤1.5h）→
Phase B 贪心（状态空间 = {liquidity 档, 过滤集合}，连续 2 轮零采纳提前
收敛，≤4.5h）→ Phase C 终审 K=21（≤1h）。各窗先到先停。

### 2.4 方向预测（跑完对照，无强立场）

广度探索不设单一方向假设。弱先验：D1 收紧（2e5+）降换手提单笔质量；
D5 量比上限砍情绪顶；D2 禁周五减周末隔夜暴露。全部待读数裁决。
