# R3 · 可交易期收益最大化战役方案（2026-08-23 · v1）

> **哲学锚（用户裁决 2026-08-23）**：策略目标 = 震荡市与趋势涨势期间**尽量吃满盈利**；
> 宏观层面变化导致的深度回撤**由人工风控保证**（ADR-16 延伸：择时判断权归人工）。
> 上游证据：R2 战役（ROUND_LOG R2 节）——策略 2026 年跑输池子等权 ~47pp，
> 病灶 = 急涨月踏空（回踩入场腿 + 固定倍数止盈截断趋势）+ 急跌月挨打（归人工职权）。

## 0. 目标与非目标

**目标**（可验收三条）：
1. **评估口径落地新哲学**：模拟"宏观回撤期人工拦增量"的评估线（回测假设层），
   G2/G3 在此口径重述——"吃满回撤敞口"的策略不再被 outer dd 误杀；
2. **急涨月 beta 捕获率**（新验收视图）：池子月收益 >8% 月份的策略/池子月收益比，
   ACTIVE 现状 ~40%（4 月 +5.8/+14.7）→ **目标 >50%**；
3. **可交易期收益显著为正**：模拟线口径下 outer（2026）段候选 ann > 0 且
   七门 dry-run 达到"差一门以内"。

**非目标**：
- **实盘自动宏观闸**（ADR-16 红线）：模拟线只存在于回测/搜索评估路径，
  `trading/` 永不 import 该模块——工程隔离硬约束；
- 不动 method_v0 识别内核（L3 追涨腿另立 spec，本战役只出立项判据数据）；
- 不预判 G1 门槛（R3 数据到位后随 ADR-15 修订一并裁）。

## 1. W1 · 评估口径改造（先改尺子，D0-D1，约 1 天）

### 1.1 人工风控模拟线（`discovery/manual_risk_sim.py`）

**规则（主口径）**：池子等权 20 日滚动回撤 < **−15%** 触发拦截 → 修复至 > −10%
解除（滞回防抖）。作用 = 拦**新入场**（对齐 RISK_BLOCK.flag 语义：拦增量、存量
持仓照常管理——保守下界，人工手动清仓只会更好）。

**阈值校准证据（2021-2026 全段初筛，正式校准只用 2021-2024 段防过拟合）**：

| 组合 | 触发段/天数 | 覆盖年份 | 判读 |
|---|---|---|---|
| **20d/−15%** | 9 段 / 45 天（≈3% 交易日） | 22,24,25,26 | **推荐**：无一误拦；2026 恰好 7/17–8/3 覆盖主跌段尾部+修复期 |
| 10d/−15% | 7 段 / 15 天 | 22,24,25,26 | 灵敏度对照口径（触发同日但窗短） |
| 20d/−10% | 22 段 / 125 天 | 21-26 全部 | 过宽（8% 交易日被拦，误伤震荡市） |
| 10d/−20% | 1 段 / 3 天 | 仅 24 | **2026 年 7 月完全漏掉**（阴跌型回撤 10 日窗内不到 −20%）——否决 |

7 月实测对齐：模拟线 7/17 触发 ≈ 人工第一~二周末反应（池子届时 −8~−19%），
语义上"保守近似一个第一周末动手的人工"。

**实现**：freeze 时预计算 `block_calendar`（日期 → bool 数组，O(1) 查表进
objective 热路径）；双口径输出（raw / manual-risk-adjusted）并列报告。

### 1.2 目标函数切换（搜索的方向盘对齐新哲学）

- 主目标：`min_yearly_calmar` 改在**模拟线口径**上计算（可交易期内的分年最差
  calmar）；raw 口径降为报告列（对照"没有人工时的裸策略"）；
- 口径断层处理：engine_hash 随 objective 入列自动重置（R1 先例），R2/R3 trial
  按 snapshot+hash 分界不可直比——ROUND_LOG 注记。

### 1.3 七门重述（走 ADR-15 修订流程留痕）

- G2（outer 改善）/ G3（dd 不劣化）：outer 段指标改用模拟线口径；
- 新增**报告视图（不加门）**：急涨月 beta 捕获率（§0 目标 2 口径）；
- G1/G4/G5/G6/G7 不变。

### 1.4 基线重刷

五参照（ACTIVE/3e383d/touch3/3f6365/独苗）双口径重跑——新旧尺子的对照表，
进 ROUND_LOG R3 节。

## 2. W2 · trailing 解锁大搜索（D2 一夜）

**维度解锁（R2 甜点区核心维保持 + 5 个新维）**：

| 新维 | 档位 | 对症病灶 |
|---|---|---|
| trailing_grace | [0, 3, 5, 10] | 趋势确认宽限（互锁约束已有：grace=0 → step/floor 归零） |
| trailing_step | [0.05, 0.1, 0.15] | 让利润奔跑的收紧速度 |
| trailing_floor | [0.0, 0.5] | 收紧下限 |
| tp_h_mult | [1.5, 2.0, 2.5, 3.0] | 固定止盈位放宽（截断趋势的直接参数） |
| buy_limit_atr_mult | [0.0, 0.5, 1.0] | 挂单贴颈线程度（回踩容忍） |

**主力 TPE**（R2 已证分年口径完胜网格）：budget 600、seed 固定、n-proc 6。
R2 的 rho 提前收敛（87/400，覆盖度饱和语义）由**扩维自然打开新覆盖空间**；
若仍早停，实测调整 `--rho-threshold`（默认 0.8）再跑。

**回归护栏**：trailing 互锁/止盈序约束（`discovery/constraints.py`）既有
单测必须全绿后才开搜索。

## 3. W3 · 急涨月踏空归因（D3 半天，L3 立项判据）

4/8 月（池子 +14.7%/+12.1%）信号级复盘，把踏空损失三分：
**(a) 没信号**（识别层没出）/ **(b) 没成交**（挂单等回踩不至）/ **(c) 早下车**
（止盈截断）——replay trades 逐笔现成，脚本级工作（`diag/r3_beta_capture.py`）。

**L3（追涨腿/双路入场）立项判据**：W2 跑完后急涨月捕获率仍 <50% → 立项
（动 method_v0 内核，需独立 spec + C2 等价性重新设计）；≥50% → 缓。

## 5. 风险与红线

1. **ADR-16 隔离**（最高红线）：模拟线模块只被 discovery/diag import；
   CI 加层契约测试（`tests/test_layer_contract` 家族）钉死 `trading/` 不依赖它；
2. **阈值过拟合**：正式校准只用 2021-2024 段；2025/2026 纯验证段（本文全段
   数据仅作初筛参考）；阈值变更走 ADR-15 同款修订留痕；
3. **口径断层**：R3 trial 与 R2 不可直比（hash 分界）；对外沟通统一用
   "模拟线口径"前缀；
4. **双轨冻结冲突（预埋决策点）**：掘金腿 20 日双轨冻结期内若 R3 出过门参数
   ——提前终止双轨重导快照 vs 等双轨期满再 promote，用户裁决；
5. **运维前置**：周一开盘前处置双引擎实例（1492/25364 二选一，pid 文件已 stale）
   ——D2 夜搜与引擎 18:00 pipeline 并存按 R2 经验可容忍，但周一盘中须干净。
