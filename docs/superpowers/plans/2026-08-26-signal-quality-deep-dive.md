# 信号质量深度探索 · 长周期方案（2026-08-26 定稿）

> 用户裁决：收益已够高（冻结口径 +400%），**重点转向信号质量**。本方案是 20 个交易日级的长周期深度探索设计。
> 一句话：**从「参数调优」转向「逐笔信号的理解与分层」——不问哪组参数好，问哪一类信号会赢。**

---

## 〇、为什么是现在、为什么是这个方向

战役已证伪的四条路（全部留有实证档案）：
- 参数空间已收敛：R6-8 十二步采纳 +515%、B3 再 +595%，但 G4 四+一连拒——参数调不动年段稳定性；
- 单维/交互/时间止损三次「判别力≠可治疗性」——**在给定识别内核下，用参数闸切割信号分布的边际已挖尽**；
- 泛滥→节流的弹性已测：砍信号量年化大降（cd=3 → −218pp）——量与质在参数层耦合；
- 资金摩擦已全建模：整手+min5+冻结 = −242pp——**摩擦对低质信号天然更致命**（胜率 83→76%），质量提升的实盘价值被摩擦放大。

未证伪的开放面：**逐笔信号的可预测结构**——53,134 笔流水里，赢单与输单在「参数不可见」的微观特征上是否有稳定差异（R4 解剖已给阳性线索：弱动量死/深形态死/贴颈线死三族同向复现），以及这种差异能否转化为**仓位分层**（而非过滤——三案教训：过滤丢收益，分层不丢）。

## 一、信号质量的定义（度量体系，Phase 0 交付）

质量不是单一数字，是五维档案（每笔信号打分）：

| 维度 | 度量 | 为什么 |
|---|---|---|
| Q1 期望 | 逐笔 pnl / 风险距离（风险倍数） | 单笔质量的本体 |
| Q2 稳定性 | 同特征桶在 2022-2026 每年的 Q1 | 参数优化的失败正在于年段不稳——质量分必须逐年站得住 |
| Q3 诚实性 | wf 折 universe（折末选池）下的 Q1/Q2 | 今日选池 +400% 折外 −25% 的教训：质量分必须在无前视池上重估 |
| Q4 摩擦存活性 | 冻结+整手+min5 口径下的边际贡献 | 低质信号在摩擦下先死（胜率 83→76 实证） |
| Q5 拥挤度 | 信号同日并发数 / 特征桶密度 | 同质信号扎堆 = 组合层实际只吃到排头兵 |

## 二、四阶段排程（20 交易日，收敛驱动，全程手动高功率发射）

### Phase 0 · 质量基线画像（D1-D2，一次发射 + 半天）

- **逐笔特征库 v1**（diag，一次全历史扫描落 `logs/quality/trades_features.parquet`）：每笔信号富化五族特征——
  - 几何族：H/ATR、rr、颈线触及数、底部离散度、形态时长（signal 的既有元数据 + rescan 补齐）；
  - 动量族：个股 5/20/60 日收益、距 60 日高点位置、突破日涨幅、ATR 百分位（R4 弱动量死的定量化）；
  - 量能族：突破日量比、5 日量能斜率、量价背离度；
  - 位置族：挂单价距现价深度（buy gap）、等待期天数、行业板块当日表现；
  - 环境族：池子等权 20 日动量/波动（**只做特征、不做过滤**——ADR-16 红线：池子侧 regime 不进决策，仅作标注供归因）；
- **基线画像**：五维质量档案 × 特征分桶的交叉表——当前 53k 笔的质量结构长什么样、差在哪。

### Phase 1 · 判别力普查（D3-D7，收敛驱动循环）

- **单特征判别力**：每个特征对 Q1/Q2 的分桶单调性、IC（秩相关）、年段一致性（≥4/5 年同向）——R6-2 方法学复用（预登记规则：**年段一致性是硬闸**，单年强信号不收）；
- **特征交互普查**：top 特征两两网格（对齐 R6-2 口径但换冻结摩擦 + wf 诚实双口径评估——之前否决用的今日池，质量结论必须在诚实池上重证）；
- **判别力≠可治疗性预案**：若某特征判别力强但组合口径无增益（三案重演），降级为**分层特征**（进 Phase 3 的仓位分配）而非过滤。

### Phase 2 · 质量分层原型（D8-D14，本轮核心交付）

**中心假设：质量分不用于过滤（丢信号）而用于分层（分配仓位）**——参数层三次证明砍信号伤收益，但仓位 4×7.5% 的结构下，把 7.5% 的固定仓位改为按质量分 3%-10% 的弹性仓位，量的引擎不熄火、质的上限被打开。

- 质量分模型 v0：Phase 1 存活特征的单调加权（**不用 ML**——53k 笔、几十个特征，线性打分的样本外稳健性远好于树模型，过拟合税已知高）；
- 受控 A/B：固定 7.5% vs 质量弹性仓位，冻结+整手+min5 全摩擦口径 + wf 诚实池双口径，预登记五闸（raw↑ ∧ 摩擦口径↑ ∧ 每年段不恶化 ∧ 2022 改善加权 ∧ 拥挤日不降级）；
- 敏感性：滑点 25/50bps 下的分层增益是否存活的专项（质量高的信号理应摩擦敏感度低——这本身是质量定义 Q4 的验证）。

### Phase 3 · 双轨实测与收敛（D15-D20，数据自动积累）

- 过闸的分层方案进模拟盘（QMT 主腿 pos_cap 弹性化工程 + 掘金对照）；
- 双轨逐日质量复盘：回测质量分 vs 实盘成交质量（成交率/滑点按质量分分层统计——**高分信号的执行质量是否真的更好**是双轨版的 Q4）；
- 收敛判据：5 个交易日实盘、分层增益方向与回测一致 → 固化为 v1；不一致 → 回 Phase 1（特征污染诊断）。

## 三、纪律红线（从战役教训直接继承）

1. **口径**：一切评估用冻结+整手+min5 全摩擦 + wf 诚实池；+400% 不是起点线是对照线；
2. **ADR-16**：池子侧特征只标注不过滤；个股侧特征自由；
3. **年段一致性硬闸**：任何特征/分层规则须 ≥4/5 年同向（2025 单年特化的教训）；
6. **多重比较税**：Phase 1 普查特征数 >50 → 显著性阈值按 Bonferroni 收紧；分层规则在 2022-2024 训练、2025-2026 验证（时序切分，禁随机 CV）；
5. **发射纪律**：全部手动高功率（server 自动优化已停）；每 Phase 收敛即停（r6_10 收敛驱动模式范式）；
6. **C2 冻结**：识别内核（method_v0/signal.py）仍逐字节不动——Phase 2 的仓位分层在组合层，不碰内核。
