# 大盘节流(三区缠线节流)设计提案 · DRAFT(2026-09-05)

状态:**研究设计稿,未进提案流,未部署**。依据链=
docs/research/2026-09-05-neckline-regime-dependence.md(六年 regime 实证)+
本文新增引擎模拟。按 08-25 全停裁决,任何实装须走提案 verify→DRAFT→人审。

## 0. 一句话

不是「指数<MA60 就减配」——六年证据把正确形态推到了**三区结构**:只在
「缠线带」(创业板指落在 0.97~1.00×MA60)暂停新开仓;深区(<0.97×MA60)
保留抄底通道(那是颈线法的主场,2025 的肥单都在深区);正常区满配。
只管新仓,退出永不延迟。

## 1. 证据链(为什么是三区,不是二值闸)

### 1.1 六年逐笔三区结构(66,130 笔,创业板指仪表)

| 区 | 定义 | 笔数占比 | 均笔 | 分年 |
|---|---|---|---|---|
| NORMAL | close≥MA60 | 62% | **+2.10%** | 六年每年为正(2022 除外 -1.35) |
| **缠线带** | 0.97≤close/MA60<1.00 | 15% | **-1.05%** | 2023 -2.23/2024 -2.66,六年最毒单元 |
| DEEP | close<0.97×MA60 | 23% | **+0.10%** | 中性;2025 **+5.43**(大底反转主场),2022 -1.85 |

毒药不是「空头」,是「缠线」:指数贴着趋势线拉锯时,突破信号既无趋势
确认也无恐慌出清,假突破率最高。深区反而含 capitulation-反转(策略的
天然猎场)——拦深区=砍掉 2025 型肥年(例外保住了)。

### 1.2 阈值敏感性=平台非尖峰(过拟合排除)

拦 [t×MA60, MA60) 带,六年保留组均笔(基线 +1.24%):
t=0.94→+1.84 / 0.95→+1.78 / 0.96→+1.76 / 0.97→+1.64 / 0.98→+1.50 /
0.99→+1.34。**全档位同向改善**;0.97 处带内毒度最浓(-1.05%)。
阈值是宽度-质量旋钮:0.94 砍 27% 换 +0.60pp,0.97 砍 15% 换 +0.39pp。

### 1.4 口径之辨(必须诚实):引擎年化为什么降,以及为什么仍值得做

引擎 ann 两窗都降(inner -52pp/outer -96pp)——无容量复利口径里
吞吐=王,拦 16% 交易日=砍复利事件数。但**部署腿(20万、单票 7.5% 帽、
每日 top-5)吃不到 551% 复利,它的经济学=单笔期望×仓位**:对部署口径,
六年逐笔 +0.39pp 期望提升 + 2023/2024 型毒带规避 + outer dd 改善
(-3.1→-2.2)才是相关的收益,15% 的新仓机会成本是相关代价。两口径
结论不同不是矛盾,是尺度不同——决策应按部署口径,但引擎口径的
吞吐损失必须知情并写进提案风险栏。

## 2. 规格(设计稿)

### 2.1 仪表(Gauge)

- 主仪表:**创业板指(399006.SZ)收盘价 vs 其 60 日均线**(池 67-81% 是
  创业板票;逐笔劈开最干净)。
- 辅仪表(展示用,不参与判定):双创合成(创业板指+科创50 等权)。
  **禁用科创50 单独判定**(大票代理,对池内科创小票给假读数)。
- 计算时点:每日 15:00 收盘后(EOD 链)更新;用 T-1 收盘为 T 日计划定
  状态(与 pre_open 计划时点同源,无前视)。
- 数据依赖:index_daily 湖已有 399006;实盘数据源=掘金 7002 history 或
  湖同步(与 amihud 同管道)。

### 2.2 状态机(三区,无滞回首版)

```
ratio = 创业板指收盘 / MA60
ratio ≥ 1.00        → NORMAL   新仓预算 = 100%(keep-top5 照常)
0.97 ≤ ratio < 1.00 → BAND     新仓预算 = 0%(当日不开新仓)
ratio < 0.97        → DEEP     新仓预算 = 100%(保留抄底通道)
```
- **只作用于新开仓**;止损/止盈/trailing/超时退出永不延迟、永不缩量。
- 持仓不加不减:节流不改存量仓位,只管增量。
- 阈值 0.97 首版取毒度峰值;提案期在 0.96-0.98 邻域跑敏感性(§1.2 已
  证明是平台,选点是宽度-质量偏好问题)。
- 无滞回:MA60 边缘抖动由 BAND 自身吸收(0.97-1.00 带本身就是缓冲区),
  首版不加连续确认,保持与回测口径逐位一致。

### 2.3 实盘接线(描述,未实施)

- 挂点:EOD 计划链(pre_open/明日预演)在算完当日信号后、生成委托前
  读仪表 → 状态写入当日 plan meta → BAND 日跳过新仓生成(或标记
  THROTTLE_SKIP);exp 腿镜像同逻辑。
- 观测:audit 加 `THROTTLE` 事件(状态/ratio/被跳过信号数);EOD 报告
  加节流状态行;cockpit 计划卡显示当日区态。
- 风控边界:不动 CAP.txt(人工域总仓位),不与 7.5% 单票帽交互;
  实验归因字段不变。

## 3. 风险与限制(风险官栏)

1. **2022 型全熊年救不了**:2022 三区全负(NORMAL -1.35/BAND -1.40/
   DEEP -1.85),节流只能省 BAND 的 -0.1pp 级;全熊年的答案仍是人工
   降 CAP,不是本机制。
2. **单仪表依赖**:创业板指数据断供/延迟 → fail-open(按 NORMAL 放行,
   与完整性 gate fail-open 哲学一致)并告警。
3. **阈值选择自由度**:0.94-0.99 平台内选点存在研究者自由度;提案期
   必须报告全档敏感性(本文 §1.2 即模板),verify 用未参与选点的窗口。
4. **多重检验背景**:本研究线已测 6+ 干预全部否决,本设计是唯一幸存
   者——幸存本身提高了假阳性先验,verify 门槛应更高(全窗+分年+邻域)。
5. 引擎口径吞吐损失(-52/-96pp ann)如实呈报,不藏在脚注。
