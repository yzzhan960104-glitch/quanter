# ADR：outer 段的角色纪律——选择段与报告段的分离

> 日期：2026-08-28 ｜ 状态：已裁决（0828 全库评审 W5-5，用户批准）
> 背景：全库评审发现 2026 outer 段自 R4 起被所有优化循环的**采纳判据**使用
> （r4/r5/r6_8/r6_10 的采纳闸第一判据都是 `raw_outer_ann`），叠加三项代码级缺陷
> （W5-1 扩展切分未进 worker / W5-2 engine_hash 不在 trial 去重键 / W5-3 TPE
> 收敛模式从未真跑）——"OOS 读数"在当前链条上的可信度被系统性削弱。

## 1. 裁决内容

1. **承认现状**：2026 outer 自 R4 起是**选择段**（迭代贪心 + TPE 复核都以它为
   判据），不再是处女 holdout。R8/R9 的"外层 holdout 终审"是在已被选择过的段上
   做的终审——其 VETO/PASS 的去偏含义被稀释，引用这些读数时必须注明。
2. **诚实读数锚**（沿用 R7c 双口径裁决）：任何对外引用以 **deployable 口径
   （queue_order 多值 + 多种子中位）** 为准；oracle（exit_date 先知序）读数只
   作内部对照，不得单独对外。
3. **未来采纳闸迁移**：新战役的采纳/预登记闸一律接 `portfolio_metrics_dual`
   可部署口径（已实现的正确范式），不再在 oracle 口径上打分。
4. **新窗口裁决来源**：fresh_window（同 cutoff 只裁一次、成熟 600 笔/15 日）
   是未来唯一可信的"处女窗口"裁决来源；同数据重测零信息。
5. **配套代码修复**（本 ADR 的执行部分，均已随 W5 落地）：
   - W5-1：discovery worker 真用扩展切分（inner 2021-24 各年 min 考场生效）；
   - W5-2：engine_hash 进 trial 去重键与 DSR/Pareto 读过滤（跨内核 trial 不混数）；
   - W5-3：TPE 收敛模式溢出修复（三臂宣称与事实一致）；
   - W5-4：D2_dow（buy_date 未来变量）标记 KNOWN_NON_DEPLOYABLE，采纳闸恒 VETO。

## 2. 影响面注记

- 既有结论（B3 ACTIVE、+402%/+5.7% 双口径、R7/R8 三假设否决）**不推翻**：
  它们的相对比较（同段同口径 A/B）仍然成立；受影响的是"绝对 OOS 能力"的表述。
- B3 冠军链含"TPE 臂实际未参与"事实——修复后跑一轮收敛复验（W5-6）闭账，
  预期结论不变（TPE 从未影响历史选择路径）。
