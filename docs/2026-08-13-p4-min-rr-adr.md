# ADR：min_rr 死参复活 + TPE normalize 收口（P4 Task 1 · 2026-08-13）

> P4 协议（spec §5.1）要求「单参数 one-at-a-time + inner 实证 + ADR 记录」。本 ADR 是
> P4 第一项的证据记录——此项是**搜索空间一致性修正**（非策略语义改动），依据 P3 敏感性
> 实测 + 代码考古，不涉及 method_v0/backtest 内核（engine_hash 不变）。

## 结论

**min_rr 从「死参数（normalize 强制 2.0）」复活为活参数**，TPE 采样补 normalize + is_feasible 重抽。

## 证据

1. **旧结论的考古失效**：constraints.py 耦合2 注释「method_v0 结构恒 rr=2.0」是 R3
   （2026-07-27）前的口径——当时 rr = 几何 2H/H = 恒 2.0。R3 改实际口径
   `rr = (tp2−entry)/(entry−stop_price)` 后 rr 随信号变化，`detect` 内
   `if rr < cfg["min_rr"]: return None` 使 min_rr 成为真实守卫（活参数）。
2. **P3 敏感性实测**（88 trial 语料）：min_rr 三档 inner calmar 均值 5.16/10.24/7.76
   （n=6/5/77，TPE 档样本小噪声大但**非零**）——与「死参数恒零方差」矛盾。
3. **搜索空间不一致实锤**：Sobol 采样经 filter_feasible→normalize 强制 min_rr=2.0
   （77 trial 全 2.0），TPE 采样绕过 normalize（16 trial 三档自由）——同一 engine 下
   两套采样语义，覆盖度与可比性双破坏。

## 改动

- constraints.py：撤 DEAD_MIN_RR 强制（normalize 只留 trailing 互锁）；
- search.py tpe_search_batch：建议经 normalize+is_feasible，不可行 tell FAIL 后重抽
  （≤5 次，耗尽则接受最后一组直接评估，worker 侧 n_total==0 兜底）；
- 文档/测试语义同步（含端点约束提示）。

## 影响

- engine_hash 不变（不触碰 ENGINE_FILES）；搜索空间变化 → 新采样 trial_id 与旧 88 trial
  天然错开（params 含 min_rr 值），旧 trial 仍可比（同 engine 同数据，诚实记录了当时
  参数语义）；基线已按新空间补搜（58 新 trial 落库）。
- 后续：min_rr 最优档由搜索决定（Sobol 均匀覆盖三档后敏感性结论会更可靠）。
