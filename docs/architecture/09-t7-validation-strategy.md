# ADR-09 · T7 架构演进期验证与回归防护策略

> 决策门 DG-1 · status: Accepted（推荐口径，待用户终签）· 2026-08-12
> 横切护栏：约束所有重构工单（T1/T2/T3 + W1/W2 波次）的验证手段。源自 [T7](../../plans/wayfinder/T7.md) + 综合治理总纲 spec §2.1。

## Context（为什么需要这个决策）

演进期频繁重构（engine 拆分 T1 / 适配层 T2 / 三维扩展 T3）。无回归防护 = 灾难：
- T1 拆分已靠 golden baseline + e2e_long_cycle 验行为等价（功臣）。
- 但适配层 conformance、双跑对比、性能基线**缺位**——后续重构裸奔风险。
- `06-tech-debt.md:88` 教训：过时测试积累成「既有红」掩盖真回归（曾阻塞 T13-A 合并判断）。

## Decision（四层验证 + 性能基线）

| 层 | 手段 | 覆盖什么 | 何时跑 |
|---|---|---|---|
| **L1 单元** | 现有 ~1687 测试（全量绿门） | 函数级行为 | 每 commit |
| **L2 契约（新）** | 适配层 `Protocol` conformance 测试 | 每个策略/资产/账户/经纪商实现满足接口契约 | W2 适配层落地时 |
| **L3 端到端** | e2e_long_cycle（长周期 plan→pre_open→fill→review，~4.9min） | 完整闭环行为等价 | **每波次合并前必跑** |
| **L4 双跑对比（新）** | 重构前后同输入双跑，diff 行为输出 | 重构行为等价证明 | W1-A（~200 patch 迁移）/ W2 重构时 |

**性能基线（新）**：回测速度 / 信号扫描耗时 / tick 处理延迟，首次记录存 `docs/architecture/perf-baseline.md`，CI 守 **10% 退化阈值**（超即拦）。

**CI 绿门**：全量绿门（防「既有红」积累）。每波次独立 PR，未达验证门不合并。

## 对抗性推演（拷问）

- **双跑对比对「隐式依赖时间/随机」的场景可能假绿** → L3 e2e_long_cycle（真实长周期）不可被 L4 替代，二者互补。L4 是「重构没改行为」的强证据，L3 是「真实闭环仍对」的地面真相。
- **契约测试不能替单元测试** → L2 只验接口形状，不验内部逻辑；L1 仍是基底。
- **性能基线 10% 阈值可能误拦正常波动** → 阈值是软拦（告警 + 人审），非硬阻断；首次基线需多跑几次取中位。

## Consequences

- 每波次合并成本上升（L3 4.9min + L4 双跑）——但这是「演进优先于 live」姿态的必要保险。
- 性能基线首次建立是额外工作（各 W1/W2 工单顺手记）。
- 契约测试基建在 W2 落地时才真正需要（适配层 Protocol 定义后）。
