# 多账户资金/持仓/订单隔离与路由

## Question

多策略 × 多账户下的**资金 / 持仓 / 订单**如何隔离与路由？领域模型决策：

1. **隔离强度**——账户是"软隔离"（单进程内软件契约，`AccountContext` 边界 + schema 隔离键）还是预留"硬隔离"（子进程 / 独立 QMT session）演进路径？软隔离的"一个策略 bug 污染他账户"风险如何显式防御？
2. **订单路由**——策略信号 → 账户选择 → 经纪商下单 的路由规则、归属标记、失败回滚；
3. **持仓归属**——多策略共享一个账户时，持仓如何按策略标记/拆分（position_book 的 schema 演进）；
4. **盈亏归集与对账**——多策略多账户的盈亏归集口径、对账时序。

给出领域模型 + 状态机 + 隔离边界图。
