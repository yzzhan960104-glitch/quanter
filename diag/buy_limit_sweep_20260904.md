# 挂单价溢价是否吞噬利润——推演与回测（2026-09-04）

> 问题来源：亏损归因反复指向「入场时机偏晚/追高溢价」。挂单价=颈线+N×ATR
> （当前冠军 N=2.5），追高溢价是否在整体层面吞噬利润？

## 一、机制推演

溢价 N×ATR 同时伤及 RR 的分子分母：止损锚颈线−1.5×ATR 固定 → 实际风险
=(N+1.5)×ATR 随 N 线性放大；目标 tp2=颈线+1.5×H 固定 → 期望收益被 N×ATR
直接吃掉一块。RR(N)=(1.5H−N·ATR)/((N+1.5)·ATR)——N 每增一档双重恶化。
但 N 是**挂单上限**非成交价：降 N 同时砍掉「只有浅回踩的高动量信号」
（那些恰是高质量信号）——所以整体最优不在 N 最小处，存在峰值平台。

## 三、结论

1. **逐笔层面：吞噬确凿**——最高溢价档均笔只有最低档的 46%（2.29% vs 4.96%），
   均 rr 差 5.6 倍，单调。
2. **整体层面：当前 N=2.5 不是问题**——峰值平台 2.25-2.5 内，outer 反而 2.5
   更优；全局收紧 N（降到 1.0-1.5）会把年化砍 15-33%（信号数-10~15%），
   **LLM 归因建议的「收紧 buy_limit_atr_mult」方向在整体回测中不成立**
   （归因只看浮亏持仓=幸存者偏差视角；全量视角下高 N 上限买的浅回踩信号
   是高质量来源）。
3. **正确的改进形态=溢价分层过滤**：问题不在 N 上限，在「高溢价成交笔」的
   期望劣化——按成交时溢价（如 >2.5×ATR 跳过或减半仓）分层，不砍浅回踩
   信号量。这是探索环/提案流的新方向（当前参数面无此维度，属策略增强类
   B/C 档提案）。
4. 胜率随溢价单调升（53%→86%）是真实的补偿效应——高溢价买确定性，但
   均笔收益的衰减快于胜率补偿，净期望仍单调劣化。

## 口径注记
- 年化绝对值是回测口径（无容量约束），相对比较可信
- 回测按挂单价成交=溢价伤害上界；实盘 marketable limit 贴盘口更低
- 高 N 的回撤收窄（-4.6%→-1.9%）是真实优点
